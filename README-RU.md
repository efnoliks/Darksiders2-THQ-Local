# Darksiders II — THQ Server Emulator

![Darksiders II — THQ Server Emulator](assets/logo.png)

> **Информация о моде**  
> **Версия:** 1.0 · **Игра:** оригинальная Darksiders II в Steam (App ID 50650)  
> **Назначение:** локальная эмуляция части закрытого сервиса THQ для Змеиной книги.  
> **Разработка:** с помощью GPT-6.1 Sol в Codex. Неофициальный проект, не связанный с THQ Nordic, Vigil Games или Valve.

[English](README-EN.md)

## Что делает мод

Мод позволяет открыть сетевую вкладку Змеиной книги и отправить подарок выбранному другу через обычное меню игры. При успешной отправке игра сама может открыть достижение **«Бескорыстие» / Pay It Forward**, если оно ещё не получено. Это уже проверено в оригинальной Steam-версии игры.

Это локальный эмулятор, а не восстановление всех серверов THQ. Подарки записываются в базу на Вашем компьютере. Доставка другу на другой компьютер и общий сетевой почтовый ящик не реализованы.

## Как начать

1. Полностью распакуйте архив в отдельную папку, в которой разрешена запись. Папку можно разместить вне каталога игры.
2. Запустите Steam и убедитесь, что игра закрыта.
3. Откройте **DS2-THQ.exe**. Мод найдёт установленную игру автоматически. Если появится окно выбора, укажите оригинальный **Darksiders2.exe**.
4. Дождитесь запуска игры и откройте Змеиную книгу. Во вкладке сетевых входящих выберите добавление подарка, предмет и друга.

Для работы эмулятора запускайте игру через **DS2-THQ.exe**. Не переносите EXE отдельно от остальных папок и не запускайте его прямо из ZIP. Отдельная установка Python не требуется.

## Как это работает

Лаунчер запускает локальный сервер на `127.0.0.1:18086` и передаёт игре настройки прокси только для её процесса. Запросы к поддерживаемым адресам THQ получает эмулятор. Перед подтверждением отправки он сохраняет подарок в локальную базу SQLite.

Чтобы игра приняла HTTPS-соединение, лаунчер при запуске временно заменяет данные доверенных сертификатов в памяти процесса. **EXE и DLL игры на диске, а также её машинные инструкции не изменяются. Данные в оперативной памяти изменяются** и возвращаются к исходному состоянию при новом запуске без мода. Системное хранилище сертификатов и общие настройки прокси не меняются. Мод не редактирует сохранения и не вызывает API принудительного открытия достижений.

## Что находится в архиве

| Файл или папка | Назначение |
| --- | --- |
| **DS2-THQ.exe** | Основной запуск мода и игры |
| **bin** | Сервер, встроенный Python и необходимые компоненты |
| **extras** | Необязательные инструменты и обслуживание |
| **info** | Инструкции на двух языках, логотип и лицензии компонентов |

Файлы, создаваемые во время работы, находятся в `bin/data`: почтовая база, сертификаты, журналы и выбранный путь к игре. Эта папка может содержать личные данные — не публикуйте её. Для переноса своей локальной почты сначала закройте игру, остановите сервер и перенесите всю папку мода вместе с `bin/data`.

## Дополнительные инструменты

Все команды расположены в **extras**:

- **Choose-Game.cmd** — заново выбрать EXE игры.
- **Check-Mod.cmd** — проверить путь к игре и встроенные компоненты без запуска игры.
- **Stop-Server.cmd** — остановить сервер этого экземпляра мода. Сначала закройте игру обычным способом.
- **Start-Darksiders2-Offline.cmd** — запустить игру с быстрым отказом от недоступных серверов. Сетевая Змеиная книга в этом режиме не работает.
- **Set-60FPS-NVIDIA.cmd** — установить ограничение 60 FPS в отдельном профиле Darksiders II для NVIDIA.
- **Restore-FPS-NVIDIA.cmd** — восстановить настройки из резервной копии, созданной предыдущей командой на этом компьютере.

Ограничение FPS необязательно и не применяется автоматически. Инструменты NVIDIA работают только с совместимым драйвером NVIDIA.

## Совместимость и ограничения

Поддерживается оригинальная Windows Steam-версия Darksiders II, сборка **mainline538065**. **Deathinitive Edition не поддерживается.** Лаунчер проверяет SHA-256 игры и отклоняет другую сборку:

`39FED14186C343FDF7F7D87B6FA779247A715347084D9E14A2708A0D7BF951B9`

Реализована только необходимая часть сервиса, а не все функции THQ. Для достижений требуется штатное подключение игры к Steam. Допустимость мода на SteamHunters и других сайтах охоты за достижениями не подтверждена: перед использованием для рейтингов уточните правила у их модераторов.

## Если что-то не работает

- Проверьте, что архив распакован целиком, папка доступна для записи, а игра закрыта перед запуском лаунчера.
- Если игра была перемещена, используйте `extras/Choose-Game.cmd`.
- Если порт занят другим экземпляром мода, закройте игру и остановите сервер через `extras/Stop-Server.cmd` в той папке, из которой он был запущен.
- После изменения структуры архива не копируйте файлы поверх старой версии: распакуйте комплект в новую папку. Автоматического переноса старых данных нет.
- Для диагностики используйте `extras/Check-Mod.cmd` и журналы в `bin/data`. Перед публикацией журналов проверьте их на личные данные.

## Как удалить

Закройте игру и выполните `extras/Stop-Server.cmd`. Если Вы применяли ограничение NVIDIA и хотите его отменить, сначала выполните `extras/Restore-FPS-NVIDIA.cmd`. После этого удалите папку мода. При удалении `bin/data` локальная почта и резервная копия настроек также удаляются.
